 1) نظرة عامة على المشروع:
نظام تسجيل وإدارة الطلاب هو تطبيق ويب ديناميكي يهدف إلى إدارة سجلات الطلاب وتنظيم بياناتهم يتيح النظام للمستخدمين إنشاء حسابات وتسجيل الدخول بالإضافة إلى تنفيذ العمليات الأساسية على بيانات الطلاب (الإضافة، العرض، التعديل، والحذف)

2) التقنيات المستخدمة:
   HTML5: إنشاء هيكل صفحات الموقع
   CSS3: تنسيق وتصميم صفحات الموقع
   Bootstrap 5: تصميم واجهة متجاوبة مع مختلف الأجهزة
   JavaScript: تنفيذ الوظائف التفاعلية في الموقع
    PHP: معالجة البيانات والتحقق من المدخلات على الخادم
    MySQL: تخزين وإدارة بيانات المستخدمين والطلاب
    AJAX: التحقق من نموذج إضافة الطلاب دون إعادة تحميل الصفحة

 3) الميزات الرئيسية:
  تسجيل المستخدمين وإنشاء الحسابات
  تسجيل الدخول والخروج
  تشفير كلمات المرور وإدارة جلسات المستخدمين
  إضافة بيانات الطلاب وعرضها وتعديلها وحذفها
  رفع الصور الشخصية للطلاب وحفظها
  البحث عن الطلاب باستخدام الاسم أو البريد الإلكتروني أو رقم الهاتف
  التحقق من صحة البيانات المدخلة
  تصميم متجاوب يدعم أجهزة الكمبيوتر والهواتف المحمولة

 4) هيكل قاعدة البيانات:
يستخدم المشروع قاعدة بيانات MySQL باسم:
student_registration_system
وتتضمن جدولين رئيسيين:
  جدول المستخدمين (Users):
   id: المعرف الخاص بالمستخدم
   username: اسم المستخدم
   email: البريد الإلكتروني
   password: كلمة المرور المشفرة
   created_at: تاريخ إنشاء الحساب

  جدول الطلاب (Students):
   id: المعرّف الخاص بالطالب
   name: اسم الطالب
   email: البريد الإلكتروني
   phone: رقم الهاتف
   address: العنوان
   profile_picture: مسار الصورة الشخصية
   created_at: تاريخ إضافة الطالب

   5) خطوات التثبيت والتشغيل:
1. تثبيت وتشغيل خادم Apache وقاعدة بيانات MySQL باستخدام XAMPP
2. نسخ مجلد المشروع إلى مجلد htdocs
3. فتح phpMyAdmin وإنشاء قاعدة بيانات باسم student_registration_system
4. استيراد ملف قاعدة البيانات SQL
5. ضبط إعدادات الاتصال بقاعدة البيانات داخل الملف includes/db.php
6. فتح المشروع من خلال المتصفح باستخدام الرابط التالي:
   http://localhost/svuProtal/

 6) متطلبات التشغيل:
  خادم ويب يدعم PHP
  قاعدة بيانات MySQL
  بيئة تشغيل مثل XAMPP
  متصفح ويب حديث

 7)  الهدف من المشروع:
يهدف المشروع إلى تطبيق المفاهيم الأساسية لتطوير مواقع الويب الديناميكية وإدارة قواعد البيانات من خلال بناء نظام عملي لتسجيل الطلاب وإدارة معلوماتهم بطريقة منظمة وسهلة الاستخدام
